# 像素宠物健身 iOS 原型

双击 [训练栖地 · Liquid Glass](ios-prototype.html) 离线试用。今天、一周计划、训练记录、宠物与成长四台手机可以独立操作。初稿见 [六稿总览](thumbs.html)。

打开原型时，「今天」默认展示全屏栖息地。在场景内上滑进入训练页，训练页滚到顶部后继续下滑即可回到栖息地。两个方向都随拖动缩放，短拖会回到当前画面。在训练页点整张宠物卡片也能打开栖息地，卡片插画底部渐隐至白色信息区。[手机首屏](previews/habitat-entry.png)

「今天」的宠物卡片、全屏栖息地和「宠物」页都显示从领养日起算的年龄和按宠物种类设定的体重。「宠物」页的等级、经验记录、重新领养与恢复操作位于场景内的玻璃面板。点经验或血量记录，可查看对应的训练记录或计划。

领养时可以在猫、狗、兔子和仓鼠之间选择，并预览草地、健身房、操场跑道、客厅和卧室。领养后在「宠物」点「更换背景」，可更换当前宠物在首页和全屏场景中的背景。

「记录」顶部的热力图默认显示最近的日期。左右滑动可浏览近 52 周，点击有颜色的日期可筛选当天记录。切换手动或设备来源会同步更新热力图与训练列表。

「计划」顶部显示周一开始的 ISO 周次和七天的日期范围，下方并排显示计划完成数和该周的实际训练分钟数。点周标题可以选择年份、月份和日期，确认后跳到该日期所在的周并选中当天。

「今天」标题把当天的实际训练时长换算成小时，最多显示两位小数。标题下显示距每日目标的剩余分钟数，目标默认是 30 分钟，可在新用户引导中自定。统计包含已保存的手动与设备记录。

新增训练计划和手动记录都可以直接输入训练项目。保存后，项目名称会在两处显示为最近使用的选项，浏览器允许本地存储时，刷新后也能继续使用。

页面背景和主要内容区采用白色，应用内的按钮、日历、筛选项、表单与玻璃导航使用浅灰色玻璃材质。栖息地的草地和树木使用自然绿色。在手机内滚动时，内容会穿过半透明底栏。点选标签时，玻璃胶囊滑到当前标签。点击「记录训练」或右上角的提醒按钮，可体验从控件展开的弹层。浏览器原型用 CSS 和 Web Animations 模拟 iOS 材质与转场，支持减少动态效果、减少透明度和高对比度偏好。

## 试用路径

| 场景 | 操作 |
| --- | --- |
| 完成训练 | 在「今天」点计划打开详情，点「记录训练」并保存。符合计划要求的记录会直接完成该计划 |
| 单独记录训练 | 在「记录」点「手动记录」并保存。需要计入某项计划时，从记录详情进入「关联计划」 |
| 改期与补记 | 在「今天」点计划打开详情后点「改期」。点首页的「舒展拉伸待补记」可补填前一天的训练 |
| 编辑与删除 | 在「今天」「计划」或「记录」左滑某一行，点「编辑」或「删除」。删除计划会保留实际训练记录。删除已关联的记录会重新结算对应计划 |
| 漏练与设备更正 | 在「宠物」点「血量 −1」，导入 11 月 12 日的设备记录，确认后查看原扣血撤销 |
| 死亡与恢复 | 切换到「宠物离世」，可立即重新领养。关联 11 月 12 日的设备记录后回到「宠物」，选择是否恢复团团 |
| 首次使用 | 在「场景」选择「新用户引导」，依次设置每日训练目标、领养宠物和预览栖息地。目标至少 10 分钟，超过 120 分钟时会显示休息提醒 |
| 到期结算 | 默认从 2026 年 11 月 16 日 20:00 北京时间开始。推进到 11 月 17 日 00:00 查看当天计划转为待补记，以及前一天的补记到期 |

苹果健康训练、提醒开关和演示时间在浏览器中模拟。刷新或重置会重新载入样例状态。每日累计达到该日目标后，当天训练每分钟计 1 XP，归给训练结束时在养的宠物。宠物从 Lv.1 开始，每 100 XP 升一级。训练记录修改或删除后，经验会重新计算。

## 源码与验证

`python3 design-demos/build.py` 生成原型和方向稿。`node --test design-demos/tests/training.mjs` 验证训练规则。`node design-demos/tests/browser.mjs` 用本机 Chrome 验证业务流程、玻璃动画、滚动叠层和辅助功能模式。可用 `PIXEL_CHROME` 指定 Chrome 路径，可用 `PIXEL_SCREENSHOTS` 指定截图目录。
