# 像素宠物健身 iOS 原型

「训练栖地 · Liquid Glass」最终原型为 `prototype-v1.2`，包含日常使用和更新后的新用户引导。新用户引导包含前进、返回和进入栖息地的转场，以及放大后的领养宠物预览，并支持系统的「减少动态效果」设置。

- [日常使用原型](ios-prototype.html) 从全屏栖息地进入今天、计划、回顾和宠物页面。演示板上的四台手机可以独立操作。
- [新用户引导原型](new-user.html) 从设定训练目标开始，依次领养宠物、选择栖息地。点「重置新用户演示」可重新体验。

初稿见 [六稿总览截图](previews/thumbs.jpg)。可交互的历史方向稿保存在 Git 标签 `prototype-v1.2`。

打开原型时，「今天」默认展示全屏栖息地。在场景内上滑进入训练页，训练页滚到顶部后继续下滑即可回到栖息地。两个方向都随拖动缩放，短拖会回到当前画面。在训练页点整张宠物卡片也能打开栖息地，卡片插画底部渐隐至白色信息区。[手机首屏](previews/habitat-entry.png)

「今天」的宠物卡片、全屏栖息地和「宠物」页都显示从领养日起算的年龄和按宠物种类设定的体重。「宠物」页的等级、经验记录、重新领养与恢复操作位于场景内的玻璃面板。点经验或血量记录，可查看对应的训练记录或计划。

十种宠物都有三个成长阶段。Lv.1 幼年头大身小。Lv.2 青年四肢或鳍逐渐伸展。Lv.3 起为成年，躯干和轮廓更结实。升阶时，宠物下次出现在栖息地或「今天」卡片上会播放像素成长动画。图鉴里切换阶段也可预览动画。宠物的领养天数单独显示。

「宠物」页右上角的猫爪可打开图鉴。图鉴会错开播放每只宠物的招牌动作。点任意一只可放大预览，左右滑动切换，底部可切换成长阶段。点大图里的宠物可触发动作。

点全屏场景时，像素标记会标出宠物的目标，到达后消失。点到墙面、家具、天空或水面时，目标会移到最近可走的地面。

领养时可选猫、狗、兔子、仓鼠、荷兰猪、龙猫、鹦鹉、乌龟、刺猬和金鱼。点领养预览或全屏场景里的宠物，可以看到猫轻跳冒爱心、狗摇尾巴、兔子连跳和乌龟缩壳等反应。在「今天」的全屏栖息地或「宠物」页点场景，宠物会前往该处，停留约 2.6 秒，再从那里开始在附近散步。金鱼的鱼缸会随点击移动，停留后金鱼会在原地的缸里继续游动。可预览草地、健身房、操场跑道、客厅和卧室，并在「宠物」页更换背景。

「回顾」汇总实际训练。顶部的绿色热力图默认显示最近的日期，左右滑动可浏览近 52 周，点击有颜色的日期可筛选当天训练。下方按日期分组显示项目、实际开始时间和时长。点单条记录可查看来源、关联计划，也可以编辑或删除记录。临时加练和漏同步的训练可从「补录或导入」保存。

「计划」默认只显示今天的安排。点其他日期可以看当天计划，点「显示全周」可以看这一周的全部安排。顶部仍显示 ISO 周次、日期范围、全周计划完成数和实际训练分钟数。点周标题可以选择年份、月份和日期，确认后跳到对应日期。

新增、编辑或改期时可填写计划开始时间。同一天的计划按时间排列，计划列表和详情显示已填写的时间。训练截止为计划日期次日 00:00（北京时间）。

「今天」标题把当天的实际训练时长换算成小时，最多显示两位小数。标题下显示距每日目标的剩余分钟数，目标默认是 30 分钟，可在新用户引导中自定。统计包含已保存的手动与设备记录。

新增训练计划和手动记录都可以直接输入训练项目。保存后，项目名称会在两处显示为最近使用的选项，浏览器允许本地存储时，刷新后也能继续使用。

页面背景和主要内容区采用白色。「计划」和「回顾」的控件使用浅灰色圆角块和胶囊形，搭配深色图标。底栏保留半透明玻璃材质，点选标签时，玻璃胶囊滑到当前标签。栖息地的草地和树木使用自然绿色。浏览器原型用 CSS 和 Web Animations 模拟 iOS 材质与转场，支持减少动态效果、减少透明度和高对比度偏好。

## 试用路径

| 场景 | 操作 |
| --- | --- |
| 完成训练 | 在「今天」点训练右侧的「记录」，可直接填写，或计时至少 1 分钟后将实际开始时间和已完成的分钟数带入表单。符合计划要求的记录会直接完成该计划 |
| 单独记录训练 | 在「回顾」点右上角加号，选择「手动记录」或「导入设备」。需要计入某项计划时，从记录详情进入「关联计划」 |
| 改期与补记 | 点计划打开详情后点「编辑」，可修改计划日期。点首页的「舒展拉伸待补记」可补填前一天的训练 |
| 编辑与删除 | 在「今天」或「计划」左滑计划，在「回顾」打开单条记录详情。删除计划会保留实际训练记录。删除已关联的记录会重新结算对应计划 |
| 漏练与设备更正 | 在「宠物」点「血量 −1」，导入 11 月 12 日的设备记录，确认后查看原扣血撤销 |
| 死亡与恢复 | 切换到「宠物离世」，可立即重新领养。关联 11 月 12 日的设备记录后回到「宠物」，选择是否恢复团团 |
| 首次使用 | 打开「新用户引导原型」，依次设置每日目标、领养宠物并全屏选择栖息地。前两步每 2 秒过渡到下一种彩虹色。目标至少 10 分钟，超过 120 分钟会提示休息。完成后再次打开会进入所选栖息地，点原型外侧的「重置新用户演示」可重新体验 |
| 到期结算 | 默认从 2026 年 11 月 16 日 20:00 北京时间开始。推进到 11 月 17 日 00:00 查看当天计划转为待补记，以及前一天的补记到期 |

苹果健康训练、提醒开关和演示时间在浏览器中模拟。刷新或重置会重新载入样例状态。每日累计达到该日目标后，当天训练每分钟计 1 XP，归给训练结束时在养的宠物。宠物从 Lv.1 开始，每 100 XP 升一级。训练记录修改或删除后，经验会重新计算。

## 源码与验证

`python3 design-demos/build.py` 生成日常使用和新用户引导原型。`node --test design-demos/tests/training.mjs` 验证训练规则。`node design-demos/tests/browser.mjs` 用本机 Chrome 验证业务流程、玻璃动画、滚动叠层和辅助功能模式。可用 `PIXEL_CHROME` 指定 Chrome 路径，可用 `PIXEL_SCREENSHOTS` 指定截图目录。
