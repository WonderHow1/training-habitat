# 训练栖地 iOS MVP｜产品介绍片方向

## 共同内容

暂定约 60 秒、16:9、1080p、普通话旁白、简体中文字幕，面向第一次了解项目的观众。两条内容线交叉推进。

| 内容段 | 观众应看到的内容 |
| --- | --- |
| 点子从哪来 | 近两周排过训练也漏过练的中国大陆 iPhone 大学生。临时加课打乱安排，练完没记，回头难以看清一周进度。 |
| 为什么这么设计 | 用轻量的排期、改期和记录接上训练，以宠物经验、三阶段造型和爱心反馈，让训练记录的后果可见。 |
| MVP 如何操作 | 设定每日目标、领养和选择栖息地。新增计划，选择项目、日期和时长。长按计划进行改期。开始计时并结束保存，或填实际开始和结束时间补记。展示像素升阶，到「回顾」查看训练。 |
| 怎么验证 | 两周计划训练完成率，以及漏练或宠物离世后是否继续训练。画面以研究问题收束。 |

方向板用真实 iOS 截图演示每条剪辑路线，横幅中的课业冲突是情境示意。下表为方向选择阶段的构图与运动计划，详细分镜在方向确认后完成。

| 方向 | 视觉参照与构图 | 画面如何从产品长出来 |
| --- | --- | --- |
| A 校园一周 | 借吕敬人的书籍设计思路，用版面层级组织时间、变动与下一步。左边先读校园日程，右边展示 iOS「今天」页的训练进度和栖息地。 | 让跑步条目从周二移到周三，接到原生「编辑训练计划」的日期操作。首测镜头用同一套排版收尾。 |
| B 像素陪练 | 官方《A Short Hike》预告提供宽景到小角色的景别参照。画面由原生像素跑道、放大后的兔子与嵌入的小手机组成。 | 从宠物的成长切入，镜头沿赛道进入 App。成长镜头使用同一只兔子的幼年、青年、成年和真实过渡像素帧。 |
| C 实机跟练 | 借 Apple Fitness+ 首发设备画面突出操作。深蓝背景上把计时数字与「结束并记录」作为首屏视觉锚点。 | 从正在计时开始，回到学生为什么开练，再用点按、长按和填写把计划、补记和回顾连接起来。 |
| 搭档日记 | 设计师思路候选。以服部一成的图文错位手法做海报式开场，一大一小放置成年像素猫和领养页面。 | 视觉尺寸差来自宠物成长。 |
| 设计复盘 | 东亚风格样张「宋刻本版式」。借细线与正文层级，保留横排阅读。 | 训练回顾贴近首测提问，适合在分享会强调如何验证。 |
| 手势剪辑 | App 风格样张「液态玻璃」。以两台重叠的原生界面和原生材质组织动作。 | 「今天」与计时器交接强调开始与保存，画面更接近应用预览。 |
