# 方向板打磨记录

第一轮使用无头 Chrome 渲染六个候选，查看 1600 像素宽的整体画面，再调整三张主稿。

- A 的两行时间与项目间距过紧，拉开时间列。开场补进首测人群的说明。将主画面手机换成「今天」页，让训练进度和栖息地同时可见，改期操作在第二帧单独展示。
- B 的放大像素兔和手机同样抢眼，将手机保持在次要景别，把像素兔作为前景。跑道边缘用透明蒙版接上蓝天，成长规则与三阶段形态拆到独立帧。
- C 的计时手机底缘被裁，缩小并调正角度以完整展示页面。移去重复说明计时实拍的竖排字。用浅蓝色手动记录帧和绿色回顾帧区分两次操作。

复看三张方向板时，发现三个阶段原先被等高缩放，统一改用每个源像素六倍的尺寸并底部对齐。增加截图高度，把色板和运镜说明收入整图。窄屏方向板改成单列，保留操作步骤的字号。

Python 版 Playwright 在本机缺失。用项目现有的 Chrome CDP 回归入口逐张截取方向板，并检查相框比例、标题边界、图片解码、导航状态、色板和窄屏横向溢出。
