# 截图打磨记录

用本机 Chrome 截取桌面、390 像素宽手机和记录弹层。原稿与复核截图见 [打磨前后对照](previews/polish.jpg)。

| 方向 | 第一轮截图中影响阅读或操作的问题 | 修订 |
| --- | --- | --- |
| 训练栖地 | 首页待补记入口低于首屏。宠物独立页未进入桌面首屏。窄屏重置按钮独占一行。 | 待补记移到今日任务和下次训练之间。桌面四屏错落并置。时间控件和场景选择固定为两行。 |
| 夜跑手账 | 周计划底部的新增按钮被标签栏遮住一部分。宠物状态只有小缩图。窄列的来源标签断成两个字。 | 减少列表垂直留白。独立宠物屏展示夜间场景和成长。记录行压缩日期写法并保持来源标签完整。 |
| 团团日记 | 明信片末尾的句子重复规则。来源时间都挤在记录行。下一次训练低于首屏。 | 图注改为最近一次真实成长记录。按日期分组。收短明信片并补足主屏高度。 |

四屏独立状态、详情、标签切换、手动完成、改期、补记、设备更正、死亡恢复、首次领养和手机宽度均用 Chrome 点按验证。Python Playwright 未安装，技能的自动外观体检跳过，使用浏览器截图人工复核和浏览器断言验证。

三版独立复核图保存在 Git 标签 `prototype-v1.2`。

## A 版 Liquid Glass 原型

首轮截图中，浮动栏的投影被底部容器裁切，紧邻 Home Indicator。复核时让滚动内容延伸至安全区下方，并把底栏和弹层定位在 Home Indicator 上方。抽查了桌面四台设备及 390 像素宽视窗，验证切换标签时胶囊过渡、滚动时内容穿过底栏、按钮展开弹层、提醒开关和关闭后的焦点。Chrome 的减少动态效果和高对比度模拟通过，完整业务用例与三份方向稿也通过回归。
